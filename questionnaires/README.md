# Questionnaire definitions

BigTwoBench evaluates TIPI, BFI-10, BFI-44, and BFM-50. The corresponding item text is not redistributed in this repository. Obtain each instrument from its authoritative source under its applicable terms, then place its JSON definition in this directory using the schema expected by `code/questionnaire_eval.py`.

This repository supplies the evaluation code and the four instrument identifiers only; it does not claim to redistribute third-party questionnaire content.
