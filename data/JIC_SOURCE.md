# JIC source data

BigTwoBench uses the Journal Intensive Conversations (JIC) corpus as its source dialogue corpus. The data are not copied into this repository.

Obtain JIC from its official dataset release: <https://huggingface.co/datasets/chocokiddo/jic>. The authors' accompanying project is available at <https://github.com/Sayantan-world/Beyond-Discrete-Personas>.

Users must follow the upstream dataset's terms and any applicable use requirements. This repository does not redistribute JIC dialogues, derived training subsets, model outputs, checkpoints, or logs.
